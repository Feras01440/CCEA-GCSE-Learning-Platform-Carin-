## WORKED EXAMPLES
### we.fm.u1.curve-sketching-quadratic-cubic.01 [verified] paper FM1 calc
STEM: A curve is defined by the equation $y = x^{2} - 6x + 5$
Find where it meets each axis, find its turning point, say whether that point is a maximum or a minimum, and sketch the curve.
  FIG: svg — The curve y equals x^2 - 6x + 5 with its two x-axis crossings, its y-axis crossing and its turning point labelled with coordinates
  1. Set $y = 0$: $x^2 - 6x + 5 = 0$, which factorises to $(x - 1)(x - 5) = 0$, so $x = 1$ or $x = 5$.   — Every point on the x-axis has height zero, so the crossings are the solutions of the equation itself. No calculus belongs in this line.  (MW1)  WHY: ✔Because a point on the x-axis has y = 0 | ✘Because the turning point sits on the x-axis | ✘Because dy/dx = 0 there
  2. Write the crossings as coordinates: $(1, 0)$ and $(5, 0)$.   — The question asks where the curve meets the axis, and a place on the page needs two numbers. Bare values of x lose the accuracy mark.  (W1)
  3. Set $x = 0$: $y = 5$, so the curve meets the y-axis at $(0, 5)$.   — The constant term is the height at x = 0, so this crossing can be read straight off the equation once you know why.  (W1)
  4. Differentiate: $\frac{dy}{dx} = 2x - 6$.   — The turning point is where the curve is momentarily level, and the gradient function is what tells you that. This is where calculus starts.  (MW1)
  5. Set the gradient to zero: $2x - 6 = 0$, so $x = 3$.   — Solving the derivative gives only the x of the turning point. It says nothing yet about how high the curve is there.  (M1)
  6. Substitute into the curve: $y = (3)^{2} - 6(3) + 5 = -4$, so the turning point is $(3, -4)$.   — Into the curve, never into the derivative. The derivative is zero there by construction, so it would hand back a height of nothing.  (W1)  WHY: ✔Because the height comes from y, not from the gradient | ✘Because dy/dx gives the height | ✘Because both give the same number
  7. Differentiate again: $\frac{d^{2}y}{dx^{2}} = 2$, which is positive, so $(3, -4)$ is a minimum.   — A positive second derivative means the gradient is climbing through zero: down, level, up. That is a dip.  (MW1)
  8. Sketch: mark $(1, 0)$, $(5, 0)$, $(0, 5)$ and $(3, -4)$, then draw one U through them with the coefficient of $x^{2}$ positive.   — Label every point you calculated. The sketch mark is for a picture that agrees with your own numbers, not for a neat curve.  (W2)
  FINAL: Crossings $(1, 0)$, $(5, 0)$ and $(0, 5)$; turning point $(3, -4)$, a minimum because $\frac{d^{2}y}{dx^{2}} = 2$.
  TWIN: A curve is defined by the equation $y = x^{2} + 2x - 15$
Find the coordinates of its turning point.  → algebraic (-1, -16) (equivalent)

### we.fm.u1.curve-sketching-quadratic-cubic.02 [verified] paper FM1 calc
STEM: A curve is defined by the equation $y = x(x - 5)(x - 8)$
Find where it meets the x-axis, find both turning points and say which is which.
  FIG: svg — The cubic y equals x times (x minus 5) times (x minus 8), crossing the x-axis at 0, 5 and 8, with a maximum and a minimum marked
  1. The product is zero when any bracket is zero, so $x = 0$, $x = 5$ or $x = 8$, giving $(0, 0), (5, 0), (8, 0)$.   — A factorised cubic hands you its crossings. Expanding first and then trying to factorise again would only make work.  (MW1)
  2. Expand for the calculus: $x(x - 5)(x - 8) = x^{3} - 13x^{2} + 40x$.   — The power rule needs separate terms, so the brackets have to come apart before you differentiate. Multiply the last two first, then bring in the x.  (MW1)
  3. Differentiate: $\frac{dy}{dx} = 3x^{2} - 26x + 40$.   — Each term on its own: multiply by the power, then step the power down.  (MW1)
  4. Set it to zero: $(3x - 20)(x - 2) = 0$, so $x = \frac{20}{3}$ or $x = 2$.   — A cubic's derivative is a quadratic, so there are two answers here, not one. Finding only one is a sign that a factor has been dropped.  (M1,W1)
  5. Heights: $y = 36$ at $x = 2$, and $y = -\frac{400}{27}$ at $x = \frac{20}{3}$.   — Both go back into the curve. The second one is a fraction, and it stays a fraction in the answer; the decimal is only for placing the point on the sketch.  (W1)
  6. Second derivative: $\frac{d^{2}y}{dx^{2}} = 6x - 26$. At $x = 2$ it is $-14$, so $(2, 36)$ is a maximum. At $x = \frac{20}{3}$ it is $14$, so that point is a minimum.   — Test each point separately. On a cubic the second derivative changes sign between them, which is why one of each always appears.  (MW1)  WHY: ✔Because the second derivative is negative at one and positive at the other | ✘Because the first x found is always the maximum | ✘Because a cubic has two maxima
  7. Sketch: mark the three crossings, the maximum $(2, 36)$ and the minimum at about $(6.67, -14.81)$, then draw a curve rising away to the right.   — The coefficient of x cubed is positive, so the curve comes up from the bottom left and leaves at the top right. Label every point.  (W1)
  FINAL: Crossings $(0, 0), (5, 0), (8, 0)$; maximum $(2, 36)$; minimum $\left(\frac{20}{3}, -\frac{400}{27}\right)$.
  TWIN: A curve is defined by the equation $y = x(x - 3)(x + 4)$
Write down the coordinates of the points where the curve meets the x-axis.  → algebraic (-4, 0), (0, 0), (3, 0) (equivalent)

## DIAGNOSTICS
### dx.fm.u1.curve-sketching-quadratic-cubic.pre (pre) [verified]
- p1 (Factorise a quadratic with unit leading coefficient): Three checks on what this lesson is built from. None of them is the new method, so answer from what you already know.
Factorise $x^{2} + x - 12$.
    ✔ $(x + 4)(x - 3)$ — The two numbers multiply to $-12$ and add to $+1$. That is the step a crossings question rests on.
    ✘ $(x - 4)(x + 3)$ — Those multiply to $-12$ but add to $-1$, so the middle term would come out as $-x$.
    ✘ $(x + 6)(x - 2)$ — Those multiply to $-12$ but add to $+4$. Check the sum as well as the product.
- p2 (Read the solutions from a factorised equation): Solve $(x - 2)(x + 5) = 0$.
    ✔ $x = 2$ or $x = -5$ — Each bracket is set to zero in turn, and the sign flips as you solve it.
    ✘ $x = -2$ or $x = 5$ [fm.sketch.factor-signs-not-reversed] — The signs inside the brackets have been copied straight out. Solving $x - 2 = 0$ gives $x = 2$, not $x = -2$.
    ✘ $x = -10$ — That is the product of the two constants. A product is zero when one factor is zero, which gives two separate answers.
- p3 (Differentiate a quadratic term by term): Differentiate $y = x^{2} - 6x + 5$.
    ✔ $2x - 6$ — Multiply by the power, step the power down, and the constant goes to zero.
    ✘ $2x - 6x$ — The middle term $-6x$ has power 1, so its derivative is the number $-6$, with no $x$ left.
    ✘ $2x - 6 + 5$ — The constant $5$ differentiates to zero, so it does not appear in the gradient function at all.

### dx.fm.u1.curve-sketching-quadratic-cubic.post (post) [verified]
- d1 (Find the x-axis crossings of a factorised quadratic): Where does the curve $y = (x - 4)(x + 7)$ meet the $x$-axis?
    ✔ $(-7, 0), (4, 0)$ — Each bracket set to zero, then both answers written as coordinates.
    ✘ $(7, 0), (-4, 0)$ [fm.sketch.factor-signs-not-reversed] — The constants have been copied out of the brackets without solving. $x - 4 = 0$ gives $x = 4$ and $x + 7 = 0$ gives $x = -7$.
    ✘ $x = 4$ or $x = -7$ [fm.sketch.x-value-not-coordinate] — The algebra is right. The question asks where the curve meets the axis, which is a place, so each answer needs its $y$ value as well.
- d2 (Find the height of a turning point): The curve $y = x^{2} + 2x - 15$ has $\frac{dy}{dx} = 2x + 2$, which is zero at $x = -1$. What is the turning point?
    ✔ $(-1, -16)$ — Substituting $-1$ into the curve gives $-16$.
    ✘ $(-1, 0)$ [fm.calc.turning-y-from-derivative] — That height came from substituting into $\frac{dy}{dx}$, which is zero at a turning point by definition. The height has to come from the curve.
    ✘ $(-16, -1)$ [fm.sketch.coordinates-swapped] — Both numbers are right and they are the wrong way round. The value you solved for is the $x$, and the height you worked out is the $y$.
- d3 (Name a turning point from the sign of the second derivative): At a turning point a curve has $\frac{d^{2}y}{dx^{2}} = 8$. What kind of point is it?
    ✔ A minimum — A positive second derivative means the gradient is rising through zero, so the curve falls to the point and climbs away.
    ✘ A maximum [fm.calc.second-derivative-sign-misread] — The test runs the other way: positive is a minimum and negative is a maximum. Picture the gradient going down, level, up.
    ✘ It cannot be decided without the sketch [fm.optim.nature-not-shown] — The second derivative settles it on its own, which is why the examiners ask for it rather than for a drawing.
- d4 (Find the crossings of a factorised cubic): Where does the curve $y = (x + 1)(x - 3)(x - 6)$ meet the $x$-axis?
    ✔ $(-1, 0), (3, 0), (6, 0)$ — Three brackets, three crossings, each written as a coordinate.
    ✘ $(-1, 0), (0, 0), (3, 0), (6, 0)$ [fm.calc.origin-assumed-on-cubic] — The origin has been added out of habit. Putting $x = 0$ into this cubic gives $y = 18$, so the curve passes well above $(0, 0)$.
    ✘ $(1, 0), (-3, 0), (-6, 0)$ [fm.sketch.factor-signs-not-reversed] — Each constant has been copied out with its printed sign. Solving $x + 1 = 0$ gives $x = -1$, and $x - 3 = 0$ gives $x = 3$.
