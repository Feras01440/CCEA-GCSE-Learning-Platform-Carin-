## 1. `packs/further-maths/content/fm2/velocity-time-graphs/bundle.json`

### VTG-1 — dx.fm.u2.velocity-time-graphs.pre, item 04, option b: the explanation describes an error that gives −12.5, not 30
- **Current:** stem "From an earlier topic: solve $8x = 60 + 12(x - 10)$."; option b text `"$x = 30$"`, feedback `"The bracket has been expanded as $12x - 10$. Every term inside is multiplied by 12."`
- **Why wrong:** expanding the bracket as $12x - 10$ gives $8x = 60 + 12x - 10$, so $-4x = 50$ and $x = -12.5$ — not 30. The value 30 comes from a different slip: dropping the $+60$, i.e. $8x = 12x - 120$, so $4x = 120$ and $x = 30$. Recomputed both: $-12.5$ and $30$. As written the distractor and its diagnosis describe two different mistakes, so the feedback teaches the wrong repair.
- **Fix:** change option b's feedback to `"The $+60$ has been dropped: that leaves $8x = 12x - 120$, so $4x = 120$ and $x = 30$. Keep the 60 — expanding gives $8x = 12x - 60$."` (Alternative if the bracket slip is the wanted distractor: change the option text to `"$x = -12.5$"` and keep the present feedback.) Verified: $120 \div 4 = 30$ and $(10-60)/4 = -12.5$.

### VTG-2 — dx.fm.u2.velocity-time-graphs.post, item 07: the student's line uses a velocity the stem never gives
- **Current:** stem "A car speeds up for 8 s, holds that velocity for 12 s, then brakes to rest, covering 700 m in all. A student writes $700 = \tfrac{1}{2}(30 + 0)t$ for the whole journey. What is wrong with that?"
- **Why wrong:** the stem says "holds that velocity" without ever naming it, so the 30 in the student's line has no source in the item. A learner cannot check the substitution. The same 30 m/s and 700 m appear in q.…0017, but there the car *starts* at 30 m/s and decelerates — a different journey from the one described here, which speeds up first — so the figure cannot be inferred from its neighbour either. The mathematics of the correct option is right ($700 = 15t$ would give $t = 46.67$ s, the value q.…0017(c) uses as its `one-formula-whole-journey` error), but the item is not self-contained.
- **Fix:** name the velocity in the stem: "A car speeds up from rest for 8 s to reach 30 m/s, holds 30 m/s for 12 s, then brakes to rest, covering 700 m in all. A student writes $700 = \tfrac{1}{2}(30 + 0)t$ for the whole journey." Verified consistent: with those stages the first two cover $\tfrac{1}{2}\times 8\times 30 + 12\times 30 = 480$ m, leaving 220 m, so the journey is physically possible and the whole-journey formula still gives the wrong 46.67 s.

### VTG-3 — q.…0004(main), q.…0010(main), q.…0016(c): a signed deceleration scores 0 where the scheme itself credits 1
- **Current:** q.…0004 answer `value: 3, unit "m/s²"`, scheme `MW1 "24 divided by 8"`, `W1 "3, given as a deceleration"` with `accept: ["-3 accompanied by the word acceleration"]`; `commonErrors` cover only 192 and 0.3333. q.…0010 (`value: 1`) and q.…0016(c) (`value: 1.6`) have the same shape with no signed-answer error.

The part's own bundle treats this as a live misconception — dx.post item 04 offers "−3 m/s², because deceleration is always negative" tagged `fm.kin.deceleration-sign` — and q.…0004's `accept` clause names it explicitly. Under CCEA follow-through/positive marking this response earns the method mark, so the app is under-marking by one mark on three parts.
- **Fix:** add to each part's `commonErrors`:
  `{"misconception":"fm.kin.deceleration-sign","pattern":{"kind":"numeric","value":-3,"tolerance":{"type":"absolute","value":0.005}},"feedback":"The size is right and the division 24 ÷ 8 earns the method mark (M).   and the same with `value: -1` for q.…0010 (its division is 15 ÷ 15, from the last stage) and `value: -1.6` for q.…0016(c) (16 ÷ 10) — the division named in the feedback has to change with the part. Verified with the added error in place on q.…0004: "−3" → 1/2 tagged `fm.kin.deceleration-sign`, "3" still 2/2, 192 → 0/2 and 0.3333 → 0/2 unchanged (the engine normalises the Unicode minus, so "−3" matches too).

### CAF-1 — dx.fm.u2.constant-acceleration-formulae.pre, item 03, option d: the explanation describes an error that gives 23.04, not 5.76
- **Current:** stem "From an earlier topic: Work out $\tfrac{1}{2} \times 0.8 \times 6^{2}$."; option d text `"5.76"`, feedback `"That squares $0.8 \times 6$ as a whole. Only the 6 is squared."`
- **Why wrong:** recomputed: $(0.8 \times 6)^2 = 23.04$, and $\tfrac12 (0.8 \times 6)^2 = 11.52$. Neither is 5.76. The value 5.76 is $(\tfrac12 \times 0.8 \times 6)^2 = 2.4^2$ — squaring the **whole product, half included**. The distractor is a good one (it is the "square everything" slip), but its explanation names a different mistake, so the learner is told to fix something she did not do.
- **Fix:** change option d's feedback to `"That squares the whole of $\tfrac{1}{2} \times 0.8 \times 6$: $2.4^{2} = 5.76$. The square belongs to the 6 alone, so work out $6^{2} = 36$ first."` Verified: $(0.5 \times 0.8 \times 6)^2 = 5.76$ exactly.

### CAF-2 — dx…pre, item 02, option b: the explanation describes an error that gives 29.5, not 118
- **Current:** stem "From an earlier topic: Solve $4(U + 26) = 144$."; option b text `"$U = 118$"`, feedback `"The 26 has been subtracted before the division by 4. Undo the multiplication that is outside the bracket first."`
