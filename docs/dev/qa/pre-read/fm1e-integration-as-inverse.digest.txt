## WORKED EXAMPLES
### we.fm.u1.integration-as-inverse.01 [verified] paper FM1 calc
STEM: Find $\int \left(6x^{2} - 4x + 5\right) dx$
  FIG: svg — A four-row card giving the integration rule: raise the power, divide by the new power, add the constant, and turn a constant term into a term in x
  1. Take the first term. $6x^{2}$ raises to $x^{3}$, and $6 \div 3 = 2$, giving $2x^{3}$.   — Raise the power first, then divide by the power you have just made. Dividing by the old power is the commonest slip in this topic.  (MW1)  WHY: ✔Because you divide by the NEW power, which is 3 | ✘Because you divide by the old power, which is 2 | ✘Because you multiply by the new power
  2. $-4x$ is $-4x^{1}$. It raises to $x^{2}$, and $-4 \div 2 = -2$, giving $-2x^{2}$.   — A plain term in x has power 1, so its new power is 2. Keeping the sign with the coefficient throughout avoids the usual second-term slip.  (MW1)
  3. $5$ is $5x^{0}$. It raises to $x^{1}$, and $5 \div 1 = 5$, giving $5x$.   — A constant is not left alone. It becomes a term in x, which is exactly the term that would differentiate back to it.  (MW1)
  4. Add the constant of integration: $\int \left(6x^{2} - 4x + 5\right) dx = 2x^{3} - 2x^{2} + 5x + c$.   — Without a point to pin it down, the height is unknown, so the answer is a family of curves and the letter says so. The integral sign is dropped now that the integrating is done.  (W1)
  FINAL: $2x^{3} - 2x^{2} + 5x + c$
  TWIN: Find $\int \left(12x^{2} - 6x\right) dx$. Use $c$ for the constant of integration.  → algebraic 4x^{3} - 3x^{2} + c (equivalent)

### we.fm.u1.integration-as-inverse.02 [verified] paper FM1 calc
STEM: The gradient function of a curve is $\frac{dy}{dx} = 3x^{2} - 10x + 4$, and the curve passes through the point $(3, 1)$.
Express $y$ in terms of $x$.
  FIG: svg — A single curve passing through the point (3, 1)
  1. The gradient function is given, so $y$ is found by integrating: $y = x^{3} - 5x^{2} + 4x + c$.   — The word gradient describes what has been handed to you, not what to do with it. The differentiating has already happened, so the move here is backwards.  (MW1,MW2)  WHY: ✔Because dy/dx is given and y is wanted | ✘Because the word gradient means differentiate | ✘Because the point must be substituted first
  2. Substitute the point: $x = 3$ and $y = 1$ give $-6 + c = 1$.   — The point goes into the integrated expression, never into the gradient function. The gradient function knows nothing about height.  (M1)
  3. So $c = 7$.   — One point is exactly enough: the family of curves has one unknown, and one equation settles it.  (W1)
  4. Write the curve as one equation: $y = x^{3} - 5x^{2} + 4x + 7$.   — The value of c goes inside the equation. Writing it beside the answer, or leaving the letter in place, loses the final mark.  (W2)
  FINAL: $y = x^{3} - 5x^{2} + 4x + 7$
  TWIN: The gradient function of a curve is $\frac{dy}{dx} = 8x - 3$, and the curve passes through $(1, 4)$.
Express $y$ in terms of $x$.  → algebraic y = 4x^{2} - 3x + 3 (equivalent)

### we.fm.u1.integration-as-inverse.03 [verified] paper FM1 calc
STEM: A curve has $\frac{dy}{dx} = 8x^{3} - 5 + \frac{12}{x^{3}}$ and passes through the point $(1, 4)$.
Find an expression for $y$.
  FIG: svg — A four-row card taking a term with a negative power through the rewrite, the raised index, the division and the answer written back over the line
  1. Rewrite the fraction as a power: $\frac{12}{x^{3}} = 12x^{-3}$.   — The rule only speaks about powers of x, so anything under a line comes up as a negative index before anything else happens.  (M1)
  2. $8x^{3}$ raises to $x^{4}$ and $8 \div 4 = 2$, giving $2x^{4}$. The constant $-5$ becomes $-5x$.   — Two ordinary terms, done the ordinary way. Finish each one before moving on.  (MW1)
  3. $12x^{-3}$ raises to $x^{-2}$, and $12 \div -2 = -6$, giving $-6x^{-2}$, which is $-\frac{6}{x^{2}}$.   — The index goes up, so -3 becomes -2, and the new power is negative, which is where the sign of the answer comes from.  (W1)  WHY: ✔Because the new power is -2 and dividing by it changes the sign | ✘Because the index goes down to -4 | ✘Because the sign of the coefficient never changes
  4. So $y = 2x^{4} - 5x - \frac{6}{x^{2}} + c$.   — Collect the three terms and add the constant. The negative power can stay as an index or go back over the line, and CCEA prints it over the line.  (W2)
  5. Substitute $(1, 4)$: $-9 + c = 4$, so $c = 13$ and $y = 2x^{4} - 5x + 13 - \frac{6}{x^{2}}$.   — A quick check: putting $x = 1$ into the finished curve gives $4$, which is the point you were given.  (M1,W3)
  FINAL: $y = 2x^{4} - 5x + 13 - \frac{6}{x^{2}}$
  TWIN: Find $\int \left(\frac{6}{x^{3}}\right) dx$. Use $c$ for the constant of integration.  → algebraic -\frac{3}{x^{2}} + c (equivalent)

## DIAGNOSTICS
### dx.fm.u1.integration-as-inverse.pre (pre) [verified]
- p1 (Differentiate a single power of x): Three checks on what this lesson is built from. None of them is the new method, so answer from what you already know.
Differentiate $y = 2x^{3}$.
    ✔ $6x^{2}$ — Multiply by the power and step the power down. Integration is about to run this backwards.
    ✘ $2x^{2}$ — The power steps down, and the coefficient is also multiplied by that power, so the $2$ becomes $6$.
    ✘ $6x^{3}$ — The coefficient is right. The power has to step down as well, from $3$ to $2$.
- p2 (Move a power from under the line to a negative index): Write $\frac{6}{x^{3}}$ using a single power of $x$.
    ✔ $6x^{-3}$ — A power under the line changes sign as it comes up. That rewrite is what lets the integration rule reach the term.
    ✘ $6x^{3}$ — Crossing the line changes the sign of the index, so the $3$ becomes $-3$.
    ✘ $-6x^{3}$ — The sign that changes belongs to the index, not to the coefficient. The $6$ stays positive.
- p3 (Divide by a negative number): What is $12 \div -2$?
    ✔ $-6$ — A positive divided by a negative is negative. This exact division appears whenever a negative power is integrated.
    ✘ $6$ — The sign of a quotient follows the signs of the two numbers, and here one of them is negative.
    ✘ $-24$ — That is $12 \times -2$. The question divides.

### dx.fm.u1.integration-as-inverse.post (post) [verified]
- d1 (Integrate a single power of x): What is $\int 6x^{2}\,dx$?
    ✔ $2x^{3} + c$ — The power rises to $3$ and $6 \div 3 = 2$.
    ✘ $6x^{3} + c$ [fm.int.coefficient-not-divided] — The power has risen correctly. The coefficient still has to be divided by that new power of $3$.
    ✘ $3x^{3} + c$ [fm.int.divided-by-original-power] — The division has used the old power of $2$. It is the new power, $3$, that the coefficient is divided by.
- d2 (Remember the constant of integration): A candidate writes $\int \left(12x^{2} - 6x\right) dx = 4x^{3} - 3x^{2}$. What is missing?
    ✔ $+ c$ — Every indefinite integral ends with the constant, because a constant differentiates away and cannot be recovered.
    ✘ Nothing; the answer is complete [fm.int.constant-omitted] — The integrating is right and the answer is one mark short. Without a point to fix it, the height is unknown, so $+ c$ belongs there.
    ✘ The integral sign in front of the answer [fm.int.constant-omitted] — The integral sign is dropped once the integrating is done; keeping it says the work is unfinished. What is missing is the constant.
- d3 (Choose the direction from what the question gives): A question reads: the gradient function of a curve is $\frac{dy}{dx} = 6x + 1$ and the curve passes through $(2, 5)$. Find the equation of the curve. What is the first move?
    ✔ Integrate $6x + 1$ — The derivative is given and the curve is wanted, so the journey is backwards.
    ✘ Differentiate $6x + 1$ [fm.int.gradient-word-triggers-differentiation] — The word gradient describes what you have been handed, not what to do with it. Differentiating would give $6$, which is the second derivative.
    ✘ Use $y = mx + c$ with the given point [fm.int.gradient-word-triggers-differentiation] — That formula is for a straight line of constant gradient. Here the gradient changes with $x$, so the curve is not a line.
- d4 (Integrate a negative power): What is $\int \frac{6}{x^{3}}\,dx$?
    ✔ $-\frac{3}{x^{2}} + c$ — The index rises from $-3$ to $-2$, and $6 \div -2 = -3$.
    ✘ $-\frac{2}{x^{2}} + c$ [fm.int.divided-by-original-power] — The index has risen correctly. The division has used the old index $-3$ rather than the new one $-2$.
    ✘ $-\frac{3}{x^{3}} + c$ [fm.int.power-not-raised] — The division by $-2$ is right, so the new power was worked out. The index itself still has to rise from $-3$ to $-2$.
- d5 (Substitute the point into the integrated expression): A curve has $\frac{dy}{dx} = 6x + 1$, so $y = 3x^{2} + x + c$, and it passes through $(2, 5)$. Which substitution finds $c$?
    ✔ $14 + c = 5$ — Putting $x = 2$ into the integrated expression and setting it equal to $y$ gives $c = -9$.
    ✘ $13 + c = 5$ [fm.int.point-substituted-into-gradient] — That value came from the gradient function. The gradient function says nothing about height, so the point belongs in the integrated expression.
    ✘ $c = 5$ [fm.int.constant-omitted] — That would only be true if the rest of the expression were zero at that point. Work out the integrated terms at $x = 2$ first.
